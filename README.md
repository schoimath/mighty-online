# Mighty Club · 마이티 온라인

친구들과 방 코드를 나누고 브라우저에서 즐기는 5인 마이티입니다. [게임 열기](https://schoimath.github.io/mighty-online/)

## 플레이

1. 한 사람이 **방 만들기**를 누르고 닉네임을 정합니다.
2. 대기실의 초대 링크나 6자리 방 코드를 친구에게 보냅니다. 친구는 링크를 열거나 **방 참가하기**에서 코드를 입력합니다.
3. 방장이 **게임 시작**을 누르면 다섯 자리에 각각 10장씩 배분합니다. 빈자리는 AI가 맡습니다. **혼자 연습하기**에서는 같은 규칙을 설정하고 AI 네 명과 시작할 수 있습니다.

대기실에서 원하는 빈자리를 누르면 바로 옮깁니다. 다른 사람이 앉은 자리를 누르면 교환을 요청하고, 상대가 수락하면 두 사람이 자리를 바꿉니다. 방장이 자리를 옮겨도 방장 권한은 그대로입니다. 첫 판은 1번 자리에서 입찰을 시작합니다.

방을 만들거나 대기실의 **테이블 규칙**에서 최저 공약(13~20점), 초구 프렌드, 초구 조커콜, 마지막 트릭의 조커 효력을 정할 수 있습니다. 새 방은 최저 14점으로 시작합니다. 초구 프렌드는 허용하고 초구 조커콜과 마지막 트릭 조커 효력은 꺼져 있습니다. 마지막 트릭 조커 효력을 켜면 조커가 기루다를 이깁니다. 마이티가 나오거나 조커콜이 선언되면 조커는 이길 수 없습니다. 변경한 설정은 같은 방의 다음 판에도 적용됩니다. 게임 중 **게임 규칙**에서 현재 설정을 확인할 수 있습니다.

낼 수 있는 손패를 한 번 누르면 카드가 내 자리 앞으로 나갑니다. 마이티가 나오면 해당 카드에 **마이티**가 표시됩니다. 주공이 그 카드를 부르면 **마이티 프렌드**로 표시합니다. 스페이드가 기루다일 때는 다이아몬드 A가 마이티입니다. 조커로 먼저 낼 때 요구할 무늬와 조커콜 선언 여부는 해당 카드를 누르기 전에 손패 위에서 정할 수 있습니다.

공개된 점수 카드는 각자 자리 옆에 모두 펼쳐집니다. 주공의 더미는 처음부터 덮고, 프렌드의 정체가 밝혀지면 이전에 획득한 카드도 모두 덮습니다. 판이 끝나면 주공 팀의 최종 점수를 확인할 수 있습니다.

결과 화면에서 방장이 **다시 한 판**을 누르면 같은 자리와 규칙으로 바로 새 카드를 받습니다. 첫 입찰자는 다음 자리로 넘어갑니다. 새 참가자를 받거나 규칙을 바꾸려면 **대기실로 돌아가기**를 누르세요. 연습 게임에서도 바로 재경기하거나 규칙을 바꿔 시작할 수 있습니다.

카드를 나누고 내고 모을 때 짧은 카드 소리가 납니다. 게임 상단의 스피커 버튼으로 효과음을 켜거나 끌 수 있습니다. 이 설정은 사용 중인 브라우저에 저장됩니다.

온라인 방의 **채팅**은 화면 아래쪽에 열립니다. 제목 부분을 마우스나 손가락으로 끌어 원하는 곳에 놓을 수 있습니다. 대기실과 게임 테이블, 같은 방의 재경기에서 최근 메시지 60개가 이어집니다.

## 컴퓨터 플레이어

AI는 한 판이 끝났을 때 자기 팀이 얻은 점수와 승리를 보상으로 삼아, 어떤 카드를 낼지 평가하는 가중치를 오프라인에서 학습했습니다. 실제 대국에서는 자기 손패와 테이블에서 본 카드를 바탕으로 가능한 상대 패를 여러 번 나눠 보고, 후보 카드를 냈을 때 판이 어떻게 끝나는지 비교합니다. 주공으로 바닥패를 교환할 때는 지키기 어려운 점수 카드를 묻거나 특정 무늬를 비울 기회도 고려합니다. 카드 선택은 방장의 브라우저에서 계산합니다.

학습에 쓰지 않은 패 400개에서 한 자리씩 새 AI로 교체해 기본 규칙으로 2,000번 비교했습니다. 나머지 네 자리는 기존 AI가 맡았습니다. 교체한 자리의 팀 승률은 기존 AI **53.30%**(1,066승), 새 AI **61.55%**(1,231승)였습니다. 바닥패 교환을 양쪽 모두 예전 방식으로 고정하면 새 AI의 팀 승률은 **59.55%**였습니다.

학습은 `node train-bot.mjs train`, 카드 내기 평가는 `node train-bot.mjs evaluate`, 바닥패 교환 평가는 `node train-bot.mjs evaluate-exchange`로 재현할 수 있습니다.

## 실시간 연결

GitHub Pages가 화면과 게임 코드를 제공합니다. 참가자는 PeerJS의 공개 연결 서비스(PeerServer Cloud)를 통해 방장을 찾은 뒤 WebRTC 데이터 채널로 게임 상태를 주고받습니다. 방장의 브라우저가 손패를 배분하고, 연결된 자리와 차례를 확인한 후 각 참가자에게 개인 손패와 공개 정보만 보냅니다. [PeerJS 문서](https://peerjs.com/docs/)

방장은 한 판이 끝날 때까지 탭을 열어 두어야 합니다. 방장이 나가거나 새로고침하면 방이 닫힙니다. 진행 중에 다른 참가자가 나가면 AI가 해당 자리를 이어받습니다. 같은 방의 다음 판에는 대기실에서 다시 참가할 수 있습니다. 온라인 방에는 WebRTC와 신호 서버에 연결할 수 있는 네트워크가 필요합니다.

## 로컬 실행

Node.js 22 이상에서 별도 패키지 설치 없이 실행할 수 있습니다.

```sh
npm start
```

브라우저에서 [로컬 게임](http://127.0.0.1:4173/)을 엽니다. 게임 규칙과 세션 검증은 `npm test`로 실행합니다.

GitHub Pages 배포 원본은 `main` 브랜치의 루트입니다. 정적 파일을 수정해 푸시하면 사이트가 갱신됩니다. 배포용 PeerJS 1.5.5와 라이선스는 `vendor/peerjs-1.5.5/`에 포함되어 있습니다.
